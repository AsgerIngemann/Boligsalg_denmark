Boligsalg i Danmark

Dette kort viser boligsalg i Danmark fra den 1. januar 1992 og frem. De røde prikker repræsenterer individuelle ejendomssalg, hvor hver prik angiver en bolig, der er blevet solgt.

Varmekortet viser tætheden af boligsalg i Danmark over tid. De farvede områder viser, hvor mange salg der har fundet sted i forskellige dele af landet. Blå og lilla nuancer indikerer færre salg, mens gule grønne, røde områder markerer høj koncentration af bolighandler. Kortet giver et visuelt overblik over, hvor bolighandlen har været mest aktiv over tid.

Kortet viser et subset af alle solgte boliger svarende til en total af 100.000 salg i alt.

async function fetchGeoJSON(url) {
    if (!url) {
        console.error("Invalid URL");
        return null;
    }
    try {
        const res = await fetch(url, {
            method: "GET"
        });

        if (!res.ok) {
            throw new Error(`HTTP error! Status: ${res.status}`);
        }

        const data = await res.json(); // Convert response to JSON
        console.log(data); // Do something with the data
        return data;
    } catch (error) {
        console.error("Error fetching GeoJSON:", error);
    }
}
